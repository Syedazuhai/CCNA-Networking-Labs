\# CCNA Networking Labs



Welcome to my Cisco Networking Practical Portfolio!



I am currently studying BSc (Hons) Computer Networking, Automation and Management and preparing for the Cisco CCNA 200-301 certification.



This repository documents my hands-on networking experience using Cisco Packet Tracer.



\## Completed Projects



\### Lab 01 — VLANs and Router-on-a-Stick

Configured VLANs, trunk links and inter-VLAN routing to enable communication between different networks.



\### Lab 02 — Static Routing

Configured static routes between Cisco routers and verified end-to-end connectivity using ping and traceroute.



\### Lab 03 — Floating Static Routes and Network Failover

Designed a three-router network with primary and backup routes. Simulated a primary link failure, verified automatic failover through an alternative path and tested recovery when the primary connection was restored.
